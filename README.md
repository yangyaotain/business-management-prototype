# 业务管理系统原型

本项目是面向代理业务部经营、运营、专项及绩效分析场景的静态 HTML 原型。

## 当前完成情况

- 已搭建统一的左侧折叠菜单、顶部栏、公共主题、分页组件和页面内容框架；卡片类分页
  默认每页 9 项并支持 9/18/27 项切换，列表、表格类默认每页 10 条并支持
  10/20/50 条切换。
- 已按最新需求完成 58 项业务交付指标工作台，支持项目经理、业务组长、质量审核、
  部门负责人四角色权限、名称/状态联合过滤、默认每页 9 项且可切换 18/27 项分页、
  指标状态展示和详情抽屉。
- 已补充登录页面、手机/邮箱验证码两步找回密码、公共用户信息下拉、
  个人资料修改与密码修改交互。
- 系统管理已按参考原型完成用户管理和角色管理；用户管理包含组织树维护、筛选、
  批量操作、分页、查看与编辑等交互，角色管理仅配置功能权限。
- 已完成人效看板，支持部门、业务组、个人三级下钻，展示人均产值、人均产能、
  人均时效和人均净利润，并提供角色权限视图、统计周期及业务类型筛选。
- 已完成运营看板，支持部门、业务组、个人三级同页下钻，按代理、造价、通用业务类型
  展示本年实际值、全年目标、序时达成情况、业务组对比和未达标指标，运营指标卡支持
  每页 9/18/27 项分页。
- 已完成客户评价页面，提供评价回收分析、评分分布、问题类型和评价明细穿透。
- 已完成绩效看板，支持部门/业务组切换、目标值与挑战值配置、达成率与差距计算、
  异常识别、业务组对比和指标详情。
- 已完成专项管理，支持专项创建与编辑、状态页签、站内消息提醒、进度直接填报、
  状态调整及列表分页，并通过结果看板呈现完成率、延迟率及计划/实际进度对比。
- 经营管理已拆分数据报表和数据报告两个独立页面；数据报表支持角色、周期、业务类型、
  三级穿透、指标明细及 Excel 导出，数据报告按月度报告和季度报告分别展示近一年归档。
- 原始需求文件已归档到 `materials/`。
- 需求范围、菜单结构和后续设计依据记录在 `docs/需求与原型框架梳理.md`。

## 打开方式

直接打开项目根目录的 `index.html`，将自动进入 `pages/login.html`；使用页面内
演示账号登录后进入工作台。

本项目为静态原型，不依赖后端服务。
